HOW IT WORKS
Each wire carries data directly from one agent's output to another's input. Blue solid = normal flow. Red dashed = conditional branch. Data shape is defined by the source agent.

Pros

  • Simplest mental model — follow the arrows
  • Data flow is immediately visible
  • Easy to build — just edges between nodes
  • Conditional branches with dashed lines
  • Works great for linear pipelines (A → B → C)

Cons

  • Tightly coupled — Agent B must know Agent A's output shape
  • Gets messy with fan-out (1 agent → 10 listeners)
  • No way to broadcast events to unknown listeners
  • Adding a new agent means rewiring existing connections

Message Bus Node

HOW IT WORKS
Publishers push events to the Bus with a topic name. Subscribers wire to the Bus and declare which topics they listen to. Adding a new listener doesn't require changing any existing agent — just wire it to the Bus. Orange = publish, Green = subscribe.

Pros

  • Loosely coupled — agents don't know about each other
  • Easy fan-out — one event, many listeners
  • Adding new agents doesn't rewire existing ones
  • Topic-based filtering is powerful
  • Scales well for event-driven architectures

Cons

  • Extra node on canvas (Bus) — more visual overhead
  • Harder to trace exact data flow (pub/sub is implicit)
  • Overkill for simple 2-agent "A triggers B" flows
  • Topic naming requires discipline

HOW IT WORKS
Left side: Simple linear chain uses direct blue wires — Email Parser → Classifier → Resolver. No bus needed.
Right side: Once resolved, the Resolver publishes to the Bus. Three background agents subscribe without knowing about each other.
Best of both: Use direct wires for deterministic pipelines, Bus for event fan-out. User decides per connection.

Pros

  • Maximum flexibility — right tool for each connection
  • Simple flows stay simple (direct wire)
  • Complex fan-out stays clean (Bus)
  • Matches real-world patterns — most systems use both
  • No forced complexity on simple use cases

Cons

  • Two connection types to learn (wire vs bus)
  • More complex canvas implementation
  • User needs to decide which pattern to use
