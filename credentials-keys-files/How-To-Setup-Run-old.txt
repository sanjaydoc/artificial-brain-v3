  FIRST TIME SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Step 1: Go to project folder
  ─────────────────────────────
  cd C:\Users\LENOVO\Desktop\All-projects\inventor-studio\artificial-brain-v3


  Step 2: Install dependencies
  ─────────────────────────────
  npm install


  Step 3: Set up environment file
  ────────────────────────────────
  cp .env.example .env

  Then edit .env and fill in your API keys:

    OPENROUTER_API_KEY=sk-or-v1-...
    NVIDIA_API_KEY=nvapi-...
    OLLAMA_TUNNEL_URL=https://ollama.klabs.network
    OLLAMA_TUNNEL_AUTH_TOKEN=your_token
    NEO4J_URI=bolt://localhost:7687
    NEO4J_USER=neo4j
    NEO4J_PASSWORD=brain_pass


  Step 4: Install local agent dependencies
  ──────────────────────────────────────────
  cd local-agent
  npm install
  cd ..


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  START THE APP (DEVELOPMENT)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Step 1: Start Docker containers (Neo4j + Simulator)
  ────────────────────────────────────────────────────
  docker start ab_neo4j ab_sim

  Verify they're running:
  docker ps


  Step 2: Start the app (Express + Vite)
  ────────────────────────────────────────
  cd C:\Users\LENOVO\Desktop\All-projects\inventor-studio\artificial-brain-v3
  npm run dev

  This starts:
    - Express server on port 8095 (backend API + brain)
    - Vite dev server on port 5173 (React frontend with hot reload)


  Step 3: Open browser
  ─────────────────────
  http://localhost:5173


  Step 4: Start local agent (SEPARATE TERMINAL)
  ──────────────────────────────────────────────
  cd C:\Users\LENOVO\Desktop\All-projects\inventor-studio\artificial-brain-v3\local-agent
  node agent.js --url ws://localhost:8095/agent-ws --token YOUR_TOKEN

  The agent connects to the brain and waits for tool calls.
  It will ask permission (y/n) in the terminal before executing each tool.

  START THE APP (PRODUCTION / CPANEL)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Step 1: Build frontend
  ───────────────────────
  npm run build

  This compiles TypeScript and builds React into dist/ folder.


  Step 2: Start server
  ─────────────────────
  node server.js

  Everything runs on single port 8095:
    - API at /api/*
    - React frontend at /
    - WebSocket at /ws and /agent-ws
    - Sub-apps at /businesses and /inventor-studio

  ───────────────────
  Ctrl+C in the agent terminal

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Problem: "Neo4j connection failed"
  Fix:     docker start ab_neo4j
           Wait 10s for Neo4j to boot, then restart the app

  Problem: "No sim camera / sim_ok: false"
  Fix:     docker start ab_sim
           Check: curl http://localhost:9091/state

  Problem: "All LLM providers exhausted"
  Fix:     Check .env has valid API keys
           Check: curl http://localhost:8095/api/llm/status
           Verify Ollama tunnel: curl https://ollama.klabs.network/api/tags

  Problem: "Agent not connected"
  Fix:     Open separate terminal, run:
           cd local-agent && node agent.js --url ws://localhost:8095/agent-ws --token test123

  Problem: Port 8095 already in use
  Fix:     Change PORT in .env to another port (e.g. 3000)

  Problem: npm run dev fails with module errors
  Fix:     rm -rf node_modules && npm install
