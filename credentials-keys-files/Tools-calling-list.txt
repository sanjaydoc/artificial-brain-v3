================================================================================
  TOOL TYPES
================================================================================

  LOCAL  — Routes through local_agent/agent.py running on your machine.
           Requires y/n approval in the chat UI before execution.
           Has access to your filesystem, terminal, and desktop.

  SERVER — Runs directly inside the motor_cortex container (port 9015).
           No local agent required. Web-only, no filesystem access.
